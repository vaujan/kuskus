# Security policy

Kuskus is pre-release software. Security fixes target the latest code on the default branch and the latest published release. Include your version so the maintainer can check whether it’s already fixed.

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/vaujan/kuskus/security/advisories/new). If that option is unavailable, contact the maintainer through the [GitHub profile](https://github.com/vaujan) to request a private reporting channel before sharing details. Do not disclose exploit details or private library files in a public issue.

Include the affected version, operating system, reproduction steps using synthetic data, expected behavior, and potential impact. Never include credentials, signing keys, or a personal vault. There is no guaranteed response time; this is an independently maintained project.

For launch setup and the remaining release checks, see the [public launch review](docs/22-public-launch-review.md). Maintainers should reproduce reports on a test library and coordinate disclosure with the reporter.
