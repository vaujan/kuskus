Sebelum mulai

Jawaban yang mungkin kamu butuhkan.

Bisakah saya menggunakan vault Obsidian yang sudah ada?

Bisa. Kuskus dapat mengindeks folder Markdown atau vault Obsidian tanpa mengonversi catatannya. Wikilink dasar, alias, tautan judul bagian, serta sematan catatan dan gambar didukung. Kompatibilitas ini tidak mencakup plugin Obsidian maupun semua format khusus plugin.

Apakah Kuskus mengubah berkas Markdown saya?

Membuka catatan atau beralih mode penyuntingan tidak menulis ulang Markdown. Perubahan yang kamu buat di Kuskus disimpan ke berkas aslinya. Properti YAML tetap menjadi konten milik pengguna. Kuskus menyimpan metadatanya di folder tersembunyi .kuskus dan tidak mengubah .obsidian.

Apa yang bisa digunakan tanpa internet?

Catatan, gambar, dan berkas lokal tetap tersedia tanpa internet. Membuka situs web, mengambil pratinjau tautan, atau menampilkan gambar daring membutuhkan koneksi dan menghubungi server terkait.

Bagaimana cara mencadangkan pustaka saya?

Tutup aplikasi, lalu salin seluruh folder vault, termasuk .kuskus. Menyertakan folder tersembunyi ini menjaga metadata Kuskus bersama catatan dan lampiranmu.

Platform mana yang sudah siap?

Windows menjadi target pertama untuk penginstal publik. Versi macOS dan Linux masih eksperimental. Periksa catatan rilis dan berkas yang tersedia untuk mengetahui status setiap versi sebelum menginstal.

Apakah Kuskus gratis dan sumber terbuka?

Ya. Kuskus berlisensi GPL-3.0-only. Kamu dapat menggunakan, memeriksa, memodifikasi, dan mendistribusikannya kembali sesuai lisensi tersebut. Tidak perlu akun.
